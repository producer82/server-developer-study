## 왜 서버 개발자가 되고 싶은가?
본래 목표했던 금융과 IT의 중간 지점 역할을 수행하려면, 우선 제품을 설계하고 구현해보는 과정이 필요하다고 판단함.\
그리고 이 역할을 수행하는데에 금융지식보다도, 생각보다 많은 IT 지식이 필요함을 느꼈음.

실제로도 금융과 IT의 중간 지점인 PW/PM 직무의 주니어 채용보다, 서버 개발자의 주니어 채용이 훨씬 활발하게 일어나고 있다.\
PW/PM 직무가 그만큼 훨씬 많은 경험과 지식을 필요로 한다는 증거.
